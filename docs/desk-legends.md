# Desk legends — proposal (20.11.2026)

Group labels (`group`) for every desk gallery, and desks to merge. **Every label is copied from the students' own material**: their text files, their PDFs (presentation, documentation), or text printed in the image itself (slide titles, caption tags, the interface's own step bar). Nothing is written by us. The source is given for each label.

Only change made to the source text: labels set in capitals in a screen (FreshDrop step bar, Lost & Found register card) are written in sentence case. If you prefer, the step numbers can be kept too ("01 Place item").

Contact sheets used for the check: `.tmp-review/legends/`.

**Status (20.11.2026): applied** — labels, merges and item order as below, in the project files. Choices made where the proposal left one open (to confirm with Martial):

- Return Shelf Machine Test: test-03 gets only its first tag, "Tangible Setup (V1)" (not cropped).
